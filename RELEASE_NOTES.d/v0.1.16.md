- **联网与工具可用性（长对话 / 含中文与 emoji）**：记忆的写入与召回由"按字节下标截断"改为"按 UTF-8 字符边界回退"，CLI 与网关两条路径同步修复，网关侧再对残余非法字节做一次清洗；含中文或 emoji 的长对话不再把记忆库写坏，也不再因请求体出现非法 UTF-8 而被供应商以 HTTP 400 `invalid unicode code point` 拒收——此前这一类拒绝会被上报为"网络失败"，把用户引向并不存在的连通性问题。
- **错误诊断**：模型服务拒绝（HTTP 400/422，如请求体非法）不再被归入笼统的读写错误，改为明确提示"请求被模型服务拒绝"并附上供应商返回的原文，用户可直接据此自助定位。
- **存量数据修复**：早期版本按字节截断写坏的记忆记录本轮做一次性清理（保留备份），消除会再次触发上述 400 的隐患。
